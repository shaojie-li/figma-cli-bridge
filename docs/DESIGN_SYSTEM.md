# 设计质量与执行合同

默认 document 模式复用目标文件自己的主题。下文涉及 Luigi 色板、命名、字体、图标和组件合同的规则适用于显式选用的 Luigi 示例。

版本 1.0.0，2026-11-18。适用于此后由 CLI / Figma 桌面插件生成或修改的设计；不制作 Skill，不使用 Figma AI，不升级套餐，不替换现有 Demo。

## 目标与事实源

目标是有明确产品判断、专业细节、可维护结构的设计稿。整齐或命令成功不等于设计完成，不承诺用自动评分证明“完美”。

- 数值与可执行规则：`design/policy.json`；状态合同：`design/components.json`。
- 命名：`docs/NAMING.md`；状态与组合规则：`docs/COMPONENT_STATES.md`。
- 当前项目颜色以 luigi-ui 的 `src/styles/colors.json` 为权威。这里只记录来源，不维护另一套色板；已有 Demo 快照及摘要继续有效。
- 项目风格与质量规则分离。`luigi-default` 是当前基线；`luigi-compact` 只作为可配置性候选，未经视觉验收不能发布。选择 profile 不会自动迁移现有组件。
- 图标始终使用官方 Phosphor 资产，记录名字、weight、版本、许可。仅名字含 Phosphor 不足以证明资产来源，必须核对来源记录和真实引用。

## 执行顺序与门槛

1. 读取目标用户、核心任务、真实内容、已有品牌/资产、平台和适用规范。先盘点而非默认重画。
2. 写出产品目标、气质、视觉语境、主要视觉重点和识别细节；与已有方向一致则直接推进，只有真正冲突才向用户确认。方向不能停留在“高级、简洁、现代”。
3. 确定项目 profile 与 Token 版本。先验收基础/语义变量，再验收依赖组件，然后组合产品页面。缺组件先补组件，不能以临时矩形绕过门槛。
4. 使用有限的结构化操作，读后生成 diff，带目标 fingerprint 写入。Figma 人工变更先回读，不覆盖。不得直接运行任意 AI 生成代码。
5. 脚本检查确定性规则；导出原生 PNG 检查层级、比例、中文排版、光学平衡、焦点和长内容。修正问题后只重验受影响部分。
6. 交付记录包含方向、规则/Token 版本、目标 ID、变更、检查明细、视觉证据、例外和未验证项。技术通过与视觉通过分别记录，最终产品验收不由 CLI 冒签。

## 必须坚持的质量原则

- 间距表示关系：组内更近、组间更远；同行内容共用边线，混合字号按基线，多行标签按首行。不能把所有列表强制同高，内容自适应场景允许高度变化。
- 4 px 是常规布局基准，不是所有数字的合法性规则。1 px 描边、自然文本宽度、真实视口、比例布局及合理光学补偿允许存在。
- 颜色和字体有语义用途；必要的文字/状态不能依赖颜色单独表达。字号和行高成对管理，中文不得直接套拉丁标题紧行高。
- 共享文本样式、语义变量、Auto Layout 和实例引用可追踪。不要因换风格 detach 实例或删除属性映射。
- 图标视觉尺寸与点击区域分开；平台单位分别明确 CSS px、pt、dp。密集桌面与触摸目标分别验收。
- 响应式不仅缩放：内容顺序、密度、换行和滚动要合理。验证真实目标宽度、最长标签、空值、错误和多行。
- 交互实现需检查键盘、可见焦点、读屏名称、减少动态、重复提交和失败保留输入。Figma 静态稿只能表达意图，不能证明这些运行时行为通过。

## 审美判断与规范例外

不把“禁止渐变、禁止 700 字重、禁止对称布局、禁止彩色表面”设为通用禁令。检查其是否服务内容、品牌与任务。避免无意义卡片套卡片、泛化大标题、无来源的信任数字、填空式装饰和每个区域同样抢眼。工具不以去掉渐变作为“去 AI 味”的证明。

视觉例外必须记录对象、规则、实际数值、原因与适用范围。`design.audit` 只允许针对 spacing、radius、type scale、图层语义命名的精确例外；例外必须匹配当前问题，失效时拒绝。变量循环、缺失绑定和状态覆盖不能靠例外跳过。

`technicalPassed` 只描述已执行的机械检查。`readyForProduct` 始终不会被机械审计自动置 true。当前程序没有自动计算合成背景下的对比度，也没有验证光学对齐、字体来源真实性、交互可访问性或全部 Figma 功能。

## 第三方 UI Kit

选择组件 → 核对许可、属性、状态和嵌套依赖 → 映射自有 Token/文本样式/Phosphor → 调整尺寸及布局 → 状态和 PNG 验收 → 纳入可用基线。保留结构合格的部分；大量拆解的组件可以自行实现。保存上游来源和派生版本；不承诺自动接收上游升级。原始 Kit 保留，不能直接改整个来源库或现有 Demo。
