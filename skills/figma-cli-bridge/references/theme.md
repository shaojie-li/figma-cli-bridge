# 在 Figma 使用主题模板

## 四套配色与画板切换

新建空白 Sandbox 时，先调用 `design.template`，参数为 `{}`。核对预检后用新请求 ID 提交 `{"dryRun":false}`。模板建立四个颜色集合、共享 Layout 和五个文字样式。重复初始化保留已有的角色值和对象 ID。遇到同名但不兼容的资产，先回读冲突。已有项目优先沿用其设计系统，用户选择模板时再初始化。

| 配色系列 | 亮色集合 | 暗色集合 |
|---|---|---|
| Normal | Color/Normal/Light | Color/Normal/Dark |
| Warm | Color/Warm/Light | Color/Warm/Dark |

四个集合分别包含 15 个 `color/*` 和三个渐变角色 `gradient/start`、`gradient/middle`、`gradient/end`。始终先定位集合 ID，再按角色取变量 ID。同页新画板沿用基准稿选定的配色；首张画板默认 Normal/Light。间距、控件高度、图标尺寸、圆角取共享 Layout 的 29 个尺度，字号和行高用共享 Text Style；按内容选择布局，按真实业务需要使用组件。

生成画板时用 `design.compose` 绑定颜色 ID 与文字样式 ID。根渐变使用三个色标，每个传 `{"color":"<渐变变量 ID>"}`，透明度来自角色本身。对生成的顶层画板调用 `design.theme`，如 `{"pageId":"<实际页 ID>","frameId":"<实际画板 ID>","mode":"Warm/Dark"}`。先预检，再用新请求 ID 加 `"dryRun":false` 写入。无需传调色板。选择这个画板后，本地插件的主题下拉框显示当前配色，可直接选择其他主题。通过原生 PNG 验证明暗、文字对比、告警和渐变。

用户可以这样描述页面：“用暖色暗版做一个库存预警页。先显示需要今天补货的商品，按仓库筛选，支持批量生成采购单。”主题与角色由模板提供，页面内容和操作由提示词决定。

## 接入已有设计系统


在已绑定的专用 Sandbox 中准备本次画面需要的资源。可以复制团队已有的组件与样式，也可以直接在 Figma 新建。下面的角色和名称是填写示例，实际名称、层级和颜色都由你决定。

| 画面用途 | 在 Figma 中准备 | 自定义名称示例 |
| --- | --- | --- |
| 页面底色、品牌色、正文色 | 建立本地变量集合，添加 Color 变量，在当前模式设置颜色 | 「山茶」集合中的「纸白」「山茶橙」「墨」 |
| 标题和正文 | 将选定的字体、字重、字号和行高保存为本地文字样式 | 「刊头 / 标题」「阅读 / 正文」 |
| 品牌图标 | 将可复用矢量图标做成主组件 | 「图形 / 山茶印记」 |
| 操作按钮或其他控件 | 准备主组件或组件集中的具体变体 | 「操作 / 加入书单」 |

在 Codex 中可以说：「用山茶集合的纸白作背景、山茶橙作标题，标题用刊头样式，复用我的山茶印记和加入书单组件。」只需提供有歧义的对应关系。Codex 先读文件，用变量 ID、文字样式 ID 和主组件 ID 组稿。文字和实例可编辑。以后在 Figma 调整同一个变量、共享样式或主组件，绑定它的画面会跟随 Figma 的继承规则更新。

默认 document 模式保留文档命名和布局尺寸。使用其他文件中的库资产时，先确保当前文件能读取对应变量、样式和主组件；可选中已有实例帮助定位。插件只在已绑定的专用文件中工作。

需要体验内置样本时可以明确说「在空的 Sandbox 中初始化 Luigi Button 示例」。相关样本命令和 Token 导出使用 Luigi 专属合同，普通主题组稿只需 design.read、design.compose、design.audit 和 design.export。

## 同页设计的一致性

在已有 Page 添加功能时，以用户指定的画板为基准。只给了 Page 时，优先选同一产品流程中已经验收的主画板。若同页有不同主题，核对用户要延续的流程。

- **生成前**回读基准画板和所用主组件。确认文本与颜色绑定、控件尺寸、间距、圆角、面板填充与效果，以及主次操作的组件变体。已有产品规范优先；文档未约定的细节从基准画板取值。
- **生成时**复用同一组变量、共享文字样式和组件实例。完整功能页沿用导航和内容边距；弹窗沿用标题、表单和按钮层级，按内容调整宽度与留白。同一业务状态使用相同的文字和颜色语义。
- **交付前**回读新画板的绑定与实例，和基准逐项核对。并排查看原生 PNG，检查层级、对齐、截断、遮罩与玻璃背景上的可读性。对有意偏离基准的处理说明原因。
